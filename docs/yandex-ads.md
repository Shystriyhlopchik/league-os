# РСЯ на главной странице

Подключён баннер `R-A-20290516-1` после раздела «Здесь знают твоё имя»,
непосредственно перед «ТОП 5» игроков. На остальных страницах рекламного места нет.
Если активного турнира нет и «ТОП 5» не отображается, рекламное место остаётся
на этой же позиции — перед статистикой.

## Как это работает

- Загрузчик `https://yandex.ru/ads/system/context.js` подключён один раз в
  `league-os-frontend/src/index.html`. Не добавляйте его в шаблоны компонентов.
- `YandexAdComponent` вызывает `Ya.Context.AdvManager.render` после создания
  контейнера в DOM. Вставлять `<script>` в Angular-шаблон не нужно.
- Указана тёмная тема `darkTheme: true`. Контейнер адаптируется к ширине страницы,
  резервирует минимум 250 px по высоте и не обрезает содержимое объявления.
- При отсутствии подходящего объявления вызывается штатный fallback — второй
  аргумент `render`. При фатальной ошибке рекламное место сворачивается.
  Предупреждение SDK не скрывает уже показанную рекламу.
- Если загрузчик не готов за 15 секунд (например, заблокирован), место скрывается,
  а ожидающий callback удаляется из очереди. Таймер не удаляет показанное объявление.
- При уходе с главной компонент очищает собственный блок через `destroy`,
  удаляет ожидающий callback и таймер. Повторный переход получает новый ID
  контейнера; просроченные callbacks не инициируют показ на другой странице.
- Автообновления объявлений и циклических повторных запросов нет.

Конфигурация блока и список доменов находятся в токене `YAN_CONFIG`:
`league-os-frontend/src/app/widgets/yandex-ad/yandex-ad.component.ts`.

Вызов рекламы разрешён только для `liga-dvora.ru` и `www.liga-dvora.ru`.
На `localhost`, IP-адресах и сторонних доменах компонент не создаёт контейнер
и не вызывает рекламу, чтобы разработка не создавала лишних запросов.
При этом общий загрузчик из `head` остаётся подключённым.
Зеркало `www` должно быть настроено и в кабинете РСЯ, если оно используется.

## Что нужно проверить в кабинете РСЯ

1. Сайт прошёл модерацию и активен, блок создан для нужного домена.
2. Тип блока — баннер, без требований к фиксированному размеру, несовместимых
   с доступной шириной мобильного экрана.
3. Индивидуальный `ads.txt` добавлен в `league-os-frontend/public/ads.txt`
   из предоставленного файла без изменения записей. Angular копирует его в корень
   сборки, nginx отдаёт `/ads.txt` как текст без подстановки Angular HTML.
   После деплоя проверьте `https://liga-dvora.ru/ads.txt`: должны отображаться
   восемь строк, включая `yandex.com, 2385948, DIRECT`.
   При обновлении списка в кабинете РСЯ замените файл и пересоберите фронтенд.
4. Документы сайта об обработке данных и необходимые согласия соответствуют
   фактической работе рекламы и аналитики. Эта интеграция не заменяет их проверку.

## Деплой

После сохранения изменений в Git и получения обновлённого кода на сервере:

```bash
cd /home/arman/league-os
docker compose -p league-os-prod --env-file .env \
  -f infrastructure/docker/docker-compose.prod.yml \
  up -d --build --no-deps frontend
```

Бэкенд, БД и миграции не меняются. После деплоя проверьте главную на реальном
домене без блокировщика рекламы. Не кликайте по собственным объявлениям для теста.
Проверка с заглушкой SDK не подтверждает модерацию, заполнение или доходность блока.

## Автоматические проверки

Тесты `yandex-ad.component.spec.ts` подменяют SDK и не загружают настоящую рекламу:
проверяют ожидание загрузчика, отсутствие объявления, ошибки, блокировщик,
очистку после перехода, уникальность контейнеров, ограничения домена и тёмную тему.

Из `league-os-frontend`:

```bash
npm test -- --watch=false --browsers=ChromeHeadless
npm run build -- --configuration production
```

Официальные инструкции:

- [Параметры блока и callbacks](https://yandex.ru/support/partner/ru/web/units/tag-features).
- [Файл ads.txt](https://yandex.ru/support/partner/ru/web/ads-txt-setup).

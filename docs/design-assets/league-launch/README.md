# Дворовая лига стартует — анонс для социальных сетей

Размер: 1080 × 1350 (4:5). Фирменная палитра, исходный векторный логотип и архивная фотография игроков.

## Публикация

`league-start-1080x1350.png` — готовое изображение для публикации.
Дата старта, сезон, стоимость и открытие регистрации не указаны: эти данные не предоставлены.

## Импорт в Figma

1. Установите Oswald и Manrope из папки `fonts/`. Для Figma в браузере может потребоваться Figma Font Installer.
2. Перетащите `league-start-1080x1350.svg` на страницу Figma.
3. Проверьте шрифты. Импортёр Figma может преобразовать текст в контуры; исходный SVG сохраняет отдельные текстовые элементы.
4. При необходимости используйте Frame selection, чтобы объединить импортированные слои во фрейм.

Фотография и шрифты встроены в SVG: внешние URL для изображений и шрифтов не нужны. Наличие встроенного шрифта не гарантирует его поддержку импортёром Figma, поэтому шрифты приложены отдельно.

## Редактирование и права

SVG содержит именованные группы, отдельные текстовые элементы и векторный логотип. Фотография остаётся растровым слоем.
Логотип: `league-os-frontend/public/brand/logos/stacked_white.svg`.
Фотография: `league-os-frontend/public/brand/photos/team-emotion.jpg`, предоставлена пользователем; авторство IVANOV / GEOMETRIA сохранено в подписи. Снимок используется как архивная иллюстрация лиги, а не свидетельство нового сезона. Публикация должна соответствовать разрешению правообладателя.
Лицензии шрифтов — в папке `fonts/`.

В репозитории также сохранены редактируемый шаблон `league-start-1080x1350.source.svg` и генератор `render.cjs`.
Повторная сборка из репозитория: `node render.cjs <путь к пакету sharp>`.

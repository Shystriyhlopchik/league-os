# Финальная заставка Дворовой лиги

1920 × 1080, 16:9. Без даты, команд и счёта.

## Файлы

- `league-outro-1920x1080.svg` — векторный исходник: отдельные группы, редактируемые текстовые элементы, оригинальный векторный логотип.
- `league-outro-1920x1080.png` — готовый кадр для видеоредактора.
- `fonts/` — фирменные шрифты Oswald и Manrope и их лицензии OFL.

## Импорт в Figma

1. Установите шрифты из `fonts/` в системе. Для Figma в браузере может потребоваться Figma Font Installer.
2. Перетащите SVG на нужную страницу Figma. Размер — 1920 × 1080.
3. Проверьте шрифты после импорта. Импортёр Figma может преобразовать SVG-текст в контуры; текстовые элементы сохраняются в исходном SVG и могут редактироваться в SVG-редакторе.

Если используются векторные слои без общего фрейма, выделите импорт и примените Frame selection.

## Видеомонтаж

Добавьте PNG последним кадром и задайте длительность 3–5 секунд. Сам файл статичный: анимация и звук не добавлены.

## Исходники

Логотип взят без перерисовки из `league-os-frontend/public/brand/logos/stacked_black.svg`.
Палитра: `#151919`, `#F0F1E9`, `#D6FF3F`, `#A5AFA7`, `#3A433E`.
Фотографии, внешние ссылки на изображения, команды и результаты не используются.

Для повторной генерации PNG: `node render.cjs <путь к пакету sharp>`.

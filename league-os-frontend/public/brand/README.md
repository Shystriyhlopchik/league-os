- Асфальт: `#151919`, бетон: `#F0F1E9`, лайм: `#D6FF3F`.
- Основной текст: Manrope. Крупные заголовки: Oswald.

- Дизайн-токены приложения: `src/styles.scss`, общий слой: `src/brand-system.scss`.

## Схема команд

`elements/cheboksary-map.svg` — новая декоративная SVG-схема для блока команд в фирменной палитре. Это не геоданные, точная дорожная карта или указание адресов площадок. Она заменяет старое красное PNG в интерфейсе; исходный файл сохранён. Команды, ссылки и относительные позиции пока берутся из существующего `TEAMS_MAP_MARKERS`, а не из активного турнира. Районы конкретных команд не выводятся: этих сведений в текущем источнике нет.

Фотокарточка использует три снимка из общего архива с явной подписью. Переключение иллюстрации при выборе команды не означает связь людей на снимке с этой командой. Индивидуальные фотографии потребуют подтверждённого сопоставления или отдельного поля в данных.

## Слайд-шоу главной

Список кадров, подписи и координаты кадрирования задаются в `HomeComponent.introSlides`. Автосмена — каждые 6500 мс, плавный переход — 900 мс. Есть ручные стрелки, счётчик и пауза. Ручное переключение останавливает автосмену. Она также приостанавливается при фокусе внутри секции, наведении на управление и скрытии вкладки. При `prefers-reduced-motion: reduce` доступно только ручное переключение без анимации. Незагрузившиеся кадры пропускаются; при уничтожении компонента таймер очищается.
